SauceDemo Manual Testing Project

 Project Overview

This project demonstrates manual testing of the SauceDemo web application using structured test cases, test execution, defect reporting, and test summary documentation.

The project was created to gain practical experience in Software Testing and Quality Assurance (QA) and to demonstrate fundamental manual testing skills.

 Project Objective

The objective of this project is to verify the functionality and usability of the SauceDemo application by:

- Creating and executing manual test cases
- Testing important application features and user workflows
- Identifying and documenting defects
- Recording actual and expected results
- Preparing a test execution summary
- Maintaining testing documentation in Excel

 Application Tested

Application: SauceDemo
Website: https://www.saucedemo.com/

 Testing Performed

The following areas of the application were tested:

- Login functionality
- Product listing
- Product selection
- Add to Cart
- Shopping Cart
- Checkout process

- Logout functionality
- UI and basic usability checks

 Test Documentation

The project contains the following testing documents:

1. Test Cases

"Test_Cases.xlsx"

Contains structured test cases with:

- Test Case ID

- Test Steps
- Test Data
- Expected Result
- Actual Result
- Status

2. Bug Report

"Bug_Report.xlsx"

Contains defect documentation including:

- Bug ID
- Bug Title
- Description
- Steps to Reproduce
- Expected Result
- Actual Result
- Severity
- Priority
- Status

3. Test Summary

"Test_Summary.xlsx"

Provides an overall summary of the test execution and results.

 Testing Process

The following testing process was followed:

1. Understanding the application and its functionality
2. Identifying test scenarios
3. Preparing test cases
4. Executing test cases
5. Recording actual results
6. Identifying and documenting defects
7. Reviewing test results
8. Preparing the final test summary
